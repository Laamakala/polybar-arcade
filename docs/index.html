Hardware

Guitar-controller ideas in a tiny arcade

  • Raspberry Pi Pico W / RP2040
  • Five fret buttons and LEDs
  • Two-direction strum control and LEDs
  • Two buzzers for notes and effects
  • ILI9341 in simulation, 160 x 80 ST7735 planned for hardware

Firmware

Menus, modes, and memorable names

  • State-driven menus and game screens
  • Normal and no-light challenge categories
  • Four-character printable ASCII initials
  • Top-four leaderboards for each difficulty
  • Blues-inspired startup melody and boot-time mute

Next steps

Roadmap

Persistent flash storage, joystick and whammy support, Start and Select buttons, more rhythm games, and a modular multi-file firmware architecture.
